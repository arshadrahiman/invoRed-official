
# IT-Company-Website

## Overview

The project "InvoRed Website" is a responsive website built using HTML, CSS, Bootstrap, and JavaScript. Designed to function seamlessly across all devices, the website includes essential modules such as About, Services, Portfolio, Team, Career, Contact, and FAQ. 

Whenever someone submits the contact or career forms, an email is sent to the company's email ID to ensure quick communication and follow-up. The website meets all project requirements and performs its intended functions effectively.

This is the official website of **InvoRed**, where you can explore all the features and learn more about our services.

## Note

Please be aware that the PHP Mailer feature is not functional on the deployed website. To utilize it, you'll need to download the entire project and run it locally on your computer using XAMPP or WAMP. 

Additionally, you must set up the sender's credentials in the 'mailing/mailingvariables.php' file. In the 'contactme.php' and 'careers.php' files, specify the receiver's email address. Lastly, don't forget to provide the path to the 'tmp-uploads' folder in the 'careers.php' file to store uploaded files.
